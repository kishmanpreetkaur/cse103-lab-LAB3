## Overview

This repository is created as part of the CSE103 course at K.R. Mangalam University, Gurugram.

It demonstrates basic Git and GitHub operations, Markdown documentation, and API interaction.

## Repository Structure

```text
my_first_repo/
│
├── README.md
├── MARKDOWN_GUIDE.md
├── CHANGELOG.md
├── main.py
└── .gitignore
```

## Skills Demonstrated

| Skill | Description |
|---|---|
| Git Initialization | Creating a local Git repository |
| Meaningful Commits | Recording changes with commit messages |
| Remote Push/Pull | Synchronizing local and remote repositories |
| Markdown Documentation | Creating formatted documentation |
| API Interaction | Understanding basic API concepts |

## How to Run

Clone the repository:

```bash
git clone https://github.com/kishmanpreetkaur/cse103-lab-LAB3.git
```

Open the project folder:

```bash
cd cse103-lab-LAB3
```

Run the Python file:

```bash
python3 main.py
```

## Key Learning Outcomes

- Learned how to initialize a Git repository.
- Understood how to use Git commands.
- Learned how to upload files to GitHub.
- Practiced writing Markdown documentation.
- Understood basic repository collaboration.
